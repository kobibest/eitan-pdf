# איתןPDF

תוכנה חינמית בקוד פתוח לעבודה עם קבצי PDF בעברית, ישירות על המחשב. בלי אינטרנט, בלי העלאת קבצים, בלי מנוי.

## מה היא עושה

- **ארגון עמודים:** איחוד כמה קבצים לאחד, סידור בגרירה, סיבוב, מחיקה, שכפול, עמוד ריק ושמירת עמודים נבחרים בלבד.
- **פיצול:** כל עמוד לקובץ, כל N עמודים, לפי טווחים (`1-3, 5, 8-`) או חיתוך ידני במספריים בין העמודים.
- **חתימה ומילוי:** מילוי שדות טופס ישירות על הדף, חתימה (ציור, הקלדה או תמונה), טקסט חופשי, תאריך, תמונה או חותמת, וכיסוי לבן להסתרת תוכן.
- **עריכת הטקסט הקיים:** לוחצים על שורה במסמך ומתקנים אותה. השורה הישנה נמחקת מהקובץ (לא רק מוסתרת), והחדשה נכתבת בעברית תקינה באותו מקום, גודל וצבע. אפשר גם לשנות גודל, הדגשה, יישור וצבע, או למחוק שורה.
- **אבטחה:** פתיחת קבצים מוגנים בסיסמה, הסרה והוספה של סיסמת פתיחה (AES-256), והגבלת הדפסה, העתקה ועריכה.
- **חתימה דיגיטלית עם תעודה:** מתעודה במאגר של Windows (כולל כרטיס חכם/טוקן), מקובץ ‎.pfx, או מתעודה אישית שהתוכנה יוצרת. חתימה גלויה או בלתי נראית, הוספת חתימה למסמך חתום בלי לבטל את הקודמות, ובדיקת החתימות שבמסמך.
- **סימן מים ומספור עמודים** בעברית.
- **חיפוש בקובץ (Ctrl+F):** מוצא מילים ומספרים בעברית ובאנגלית, גם עם ניקוד או גרשיים, ומסמן בדיוק את המילה שנמצאה. Enter/F3 לתוצאה הבאה.
- **דחיסה:** הקטנת הקובץ למייל ולוואטסאפ בשלוש רמות (בלי איבוד איכות, מומלצת ב-150 DPI, חזקה ב-96 DPI). רק התמונות מוקטנות, הטקסט נשאר טקסט. נשמר כעותק חדש.
- **המרה ל-Word:** קובץ ‎.docx לעריכה, עם העברית בסדר הנכון (כולל מספרים, אנגלית וסוגריים בתוך הטקסט). שורות שנשברו מתחברות בחזרה לפסקאות, ונשמרים יישור, הזחות, גופן, גודל, הדגשה וצבע (גם בתוך שורה), כותרות (תוכן העניינים ב-Word עובד), תבליטים כרשימה של Word, טבלאות (עם קווים, תאים ממוזגים ורקע, או לפי טורים של טקסט), תמונות, וכותרת עליונה ותחתונה שחוזרות בכל עמוד (מספר העמוד הופך לשדה). הגופנים של ה-PDF מוטמעים בקובץ (גם גופני CFF מומרים ל-TrueType), כך שהטקסט מוצג בדיוק באותו גופן גם במחשב שאין בו את הגופן. עמוד מעוצב או מורכב (רקעים וצורות צבעוניים, טופס עם שדות זה לצד זה, טבלאות זו לצד זו) נכנס כתמונת רקע עם הגרפיקה, וכל שורת טקסט בתיבה במקום המדויק שלה. עמוד סרוק נכנס כתמונה.
- **המרה לתמונות:** כל עמוד לתמונת JPG או PNG, ב-96, 150 או 300 DPI, או תמונה ארוכה אחת של כל העמודים (לוואטסאפ). אפשר להמיר רק חלק מהעמודים.
- **שילוב ב-Windows:** תמונה ממוזערת של העמוד הראשון בסייר הקבצים, ומיזוג או פיצול בלחיצה ימנית על קבצי PDF.
- **תמונות ל-PDF:** גוררים JPG/PNG והם הופכים לעמודים.

## למה "עברית" זה העניין

PDF לא יודע מה זה כיוון כתיבה: הוא מצייר אותיות משמאל לימין בדיוק בסדר שקיבל, ולכן כל כלי שכותב עברית לתוך PDF צריך לסדר אותה בעצמו.

המנוע ב-`src/core/hebrew.js` מסדר כל טקסט לפי אלגוריתם Unicode Bidi לפני שהוא נכתב לקובץ:

- עברית מימין לשמאל, מספרים ואנגלית בתוכה נשארים תקינים
- סוגריים משתקפים נכון
- ניקוד נשאר צמוד לאות, עם מיקום מהפונט
- שדות טופס: הערך נשמר בסדר הנכון (העתקה וחיפוש עובדים), והמראה נבנה בסדר חזותי

## התקנה (Windows)

מורידים את `EitanPDF-Setup-x.y.z-x64.exe` ומתקינים. התקנה של גרסה חדשה מעדכנת את הקיימת ושומרת הגדרות וחתימות. לא נדרשות הרשאות מנהל.
בפעם הראשונה Windows עשוי להציג אזהרת SmartScreen כי הקובץ לא חתום דיגיטלית: "מידע נוסף", ואז "הפעל בכל זאת".

## התקנה (macOS)

מורידים את `EitanPDF-mac.dmg` (קובץ אחד שמתאים גם למעבדי Apple M1 ומעלה וגם ל-Intel), פותחים אותו וגוררים את איתןPDF לתיקיית Applications.
הקובץ לא חתום אצל Apple, ולכן בפתיחה הראשונה macOS יציג הודעה שלא ניתן לאמת את התוכנה. לוחצים "סיום", ואז: הגדרות מערכת ← פרטיות ואבטחה ← בתחתית "פתח בכל זאת" ← מאשרים. זה נדרש פעם אחת בלבד.

במאק כל הכלים זמינים, חוץ משני דברים שקיימים רק ב-Windows: חתימה ממאגר התעודות של Windows (בכרטיס חכם/טוקן), ושילוב בסייר הקבצים. חתימה דיגיטלית מקובץ ‎.pfx או מתעודה אישית עובדת כרגיל. כדי לפתוח PDF באיתןPDF: קליק ימני על הקובץ ← "פתח באמצעות".

## פיתוח

```bash
npm install
npm start          # הרצה
npm test           # בדיקות למנוע (עברית, טפסים, איחוד, פיצול)
npm run dist            # בניית תוכנת התקנה ל-Windows (גם מלינוקס)
npm run dist:mac        # בניית ‎.dmg ל-macOS (רק על Mac)
```

מבנה:

```
main.js, preload.js      תהליך ראשי של Electron וגשר מאובטח לקבצים
src/core/hebrew.js       מנוע כיווניות לכתיבת עברית ל-PDF
src/core/ops.js          איחוד, פיצול, טפסים, חותמות, סימן מים, מספור
src/core/compress.js     דחיסה (משותף לדסקטופ ולאנדרואיד)
src/core/search.js       חיפוש בקובץ (משותף לדסקטופ ולאנדרואיד)
src/core/docx.js         המרה ל-Word: פסקאות, טבלאות ותמונות מתוך הטקסט שבעמוד
src/core/rasterize.js    ציור עמודים לתמונות (JPG/PNG) דרך pdf.js
src/core/fontembed.js    הטמעת גופני ה-PDF בקובץ ה-Word (כולל המרת CFF ל-TrueType)
src/core/textedit.js     קריאת הטקסט הקיים בעמוד, ומחיקת שורות לעריכה
src/renderer/            הממשק
test/                    בדיקות, קבצי דוגמה וצילומי מסך אוטומטיים
```

ספריות: [pdf.js](https://github.com/mozilla/pdf.js) לתצוגה, [pdf-lib](https://github.com/Hopding/pdf-lib) לעריכה, [bidi-js](https://github.com/lojjic/bidi-js) לכיווניות, [fflate](https://github.com/101arrowz/fflate) לאריזת קובץ ה-Word. כולן ברישיונות מתירניים (Apache-2.0 / MIT).
גופנים: Alef ו-IBM Plex Sans Hebrew, ברישיון SIL OFL.

## מגבלות ידועות

- עריכת טקסט קיים היא ברמת שורה: פסקה לא מתעמדת מחדש, והשורה נכתבת מחדש בפונט IBM Plex או Alef. בקבצים סרוקים אין טקסט לערוך.
- חתימה דיגיטלית בלי חותמת זמן מאושרת (TSA), כי זה דורש חיבור לאינטרנט. בדיקת החתימות לא בודקת את שרשרת האמון מול הרשות המאשרת.
- אי אפשר לשמור באותו קובץ גם חתימה דיגיטלית וגם סיסמה.
- המרה ל-Word: אין זיהוי טקסט (OCR), ולכן עמוד סרוק נכנס כתמונה. בעמוד רגיל, קווים וצורות שאינם טבלה (מסגרת של שדה, קו חתימה) לא עוברים; בעמוד מעוצב הם בתמונת הרקע, והטקסט בתיבות נפרדות. בגופן מוטמע יש רק התווים שהיו ב-PDF, כך שתו חדש שמקלידים בו עלול להופיע בגופן אחר. בעמוד מעוצב כל שורה היא תיבת טקסט נפרדת: מדויק במראה, פחות נוח לעריכה של פסקאות ארוכות.
